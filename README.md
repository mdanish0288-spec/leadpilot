# LeadPilot

Private lead-finding and website-demo system. See `CLAUDE.md` for goals, stack, safety rules and build order.

- `docs/design-playbook.md` — rules every client website follows
- `docs/design-resources.md` — vetted open-source libraries
- `templates/` — layout library (run `npm run templates:dev`, open http://localhost:4321)
- `scripts/screenshot.mjs` — phone + desktop screenshots and quality checks
